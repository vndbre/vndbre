# vndbre

Fresh monorepo reset for the VNDBRE project.

## Workspaces

- `packages/core` - shared API clients, domain helpers, and reusable hooks.
- `apps/web` - TanStack Start web application.
- `apps/mobile` - planned future workspace, intentionally not created yet.

## Commands

```bash
bun install
bun dev
bun build
bun typecheck
```
